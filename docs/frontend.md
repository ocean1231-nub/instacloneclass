# 프론트엔드 명세

## 목표와 범위

React + Vite로 휴대폰 화면에 맞는 인스타그램 스타일 학습용 앱을 만든다. 기준 너비는 375~430px이며 작은 화면에서도 가로 스크롤 없이 사용할 수 있어야 한다. 캡처는 화면 구성 참고 자료다. 게시물 내용과 계정은 학습용으로 준비한다.

## 화면 구성

| 화면 | 캡처 | 필수 동작 |
|---|---|---|
| 홈 피드 | 01, 02 | 게시물 목록, 사진·작성자·본문·좋아요 수·댓글 수 표시, 좋아요 토글, 댓글 화면 이동 |
| 가입·로그인 | 캡처 없음 | 사용자 이름·비밀번호 입력, 가입, 로그인, 실패 메시지, 로그아웃 |
| 프로필 | 03, 04 | 사용자 정보와 게시물 격자, 게시물이 없을 때 빈 화면; 본인 프로필 수정 |
| 게시물 작성 | 05 | 사진 선택·미리보기, 본문 입력, 등록 및 취소 |
| 탐색 | 06 | 선택: 게시물 격자와 검색. 필수 범위에서는 메뉴를 숨겨도 됨 |
| 릴스 | 07 | 선택: 화면 참고만. 영상 업로드·재생 기능은 필수 범위 밖 |
| 메시지함·새 대화 | 08, 09 | 선택: 대화 목록, 상대 선택, 메시지 주고받기 |

하단 탐색은 홈, 새 게시물, 내 프로필을 필수로 둔다. 선택 기능은 완성한 경우에만 노출한다. 가입·로그인 화면은 캡처에 없으므로 간단한 양식으로 설계한다. 댓글은 게시물에서 열리는 별도 화면 또는 패널로 만들고 목록과 작성란을 제공한다.

## 기능과 상태

- 라이트·다크 모드를 모두 지원한다. 프로필 설정에서 밝게, 어둡게, 기기 설정 따르기 중 선택하며 기본값은 기기 설정 따르기다. 선택값은 해당 브라우저에 저장하고 새로고침 후에도 유지한다. 기기 설정 따르기를 선택한 경우 기기의 테마 변경을 반영한다.
- 두 테마에서 배경, 글자, 카드, 입력란, 테두리, 버튼과 하단 메뉴의 색을 함께 바꾼다. 읽기 쉬운 명암과 버튼·입력란의 포커스 표시를 확보하고, 사용자가 올린 사진은 테마에 따라 변형하지 않는다. 제공된 캡처는 다크 모드의 배치와 분위기 참고용이며 라이트 모드는 같은 화면 구조에 밝은 색상을 적용한다.
- 회원가입 후 로그인하고 토큰을 보관해 인증이 필요한 API에 보낸다. 로그아웃 시 토큰을 지운다. 새로고침 후에도 로그인 상태를 복원한다.
- 피드는 최신순이며 작성한 게시물이 등록 후 보인다. 본인 게시물에는 삭제 버튼을 둔다.
- 좋아요는 한 계정당 게시물 하나에 한 번만 적용하고 다시 누르면 취소한다. 댓글은 본문 작성과 목록 조회를 지원한다.
- 프로필은 표시 이름, 소개, 프로필 사진을 수정한다. 다른 사용자의 프로필도 조회할 수 있다.
- 팔로우(선택)는 다른 사용자에 대한 팔로우·취소와 팔로워/팔로잉 수를 표시한다. DM(선택)은 로그인 사용자 간 1:1 대화와 메시지 목록·전송을 지원한다. 실시간 갱신은 필수가 아니며 새로고침으로 확인할 수 있다.
- 요청 중 표시, 빈 목록, 유효성 오류, 서버 오류를 사용자에게 보여준다. 글 작성과 버튼은 키보드로 조작 가능하게 하고 이미지에는 대체 텍스트를 제공한다.

## API 연결

백엔드 문서의 `/api` 경로를 사용한다. API 주소는 Vite 환경 변수로 설정하고 개발 시 로컬 서버에 연결한다. 인증 요청에는 `Authorization: Bearer <토큰>`을 사용한다. 사진은 `multipart/form-data`로 업로드하고 반환된 URL을 사용한다. 비밀번호는 화면에서 서버로만 전송하고 별도 저장하지 않는다. 모바일에서는 하단 메뉴가 본문을 가리지 않도록 여백을 확보한다.

## 완료 확인

휴대폰 폭에서 가입→로그인→사진 게시→좋아요·댓글→프로필 수정이 가능하고 새로고침 후 결과가 유지된다. 로그인하지 않은 사용자는 읽을 수 있지만 작성·반응은 로그인 화면으로 안내한다. 각 화면에서 라이트·다크 모드를 확인하고, 선택 및 기기 설정 따르기가 새로고침 후에도 유지되는지 확인한다.
