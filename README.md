# 사진 피드 수업 프로젝트

Node.js와 uv를 설치한 뒤 프로젝트 루트에서 다음 순서로 실행합니다.

1. `backend/.env.example`을 `backend/.env`로 복사하고 Supabase 연결 정보 세 가지를 직접 입력합니다. `DATABASE_URL`은 PostgreSQL 세션 풀러 주소입니다. `.env`는 Git에 올리지 않습니다.
2. `npm run dev`를 실행합니다. Vite와 FastAPI가 함께 시작되며 Vite가 표시하는 주소로 접속합니다. 필요한 화면 의존성과 Python 의존성은 첫 실행 때 설치합니다.

서버는 시작할 때 `app` 스키마의 4개 테이블을 확인하고 RLS를 활성화합니다. 정책은 만들지 않으며 연결 계정이 테이블 소유자여야 합니다. 비어 있는 DB에는 예시 사용자 2명과 게시물 6개를 추가하고, `post-images` 공개 버킷에 예시 이미지를 저장합니다. 기존 비공개 버킷의 공개 설정은 자동으로 바꾸지 않습니다.

가입·로그인, 게시물 조회·등록, 좋아요, 댓글, 프로필 수정은 FastAPI와 Supabase에 연결됩니다. 팔로우·저장·DM은 화면 데모입니다. 예시 사용자는 피드 표시용이며 로그인용 계정이 아닙니다.

## 링크 미리보기

공개 배포 주소가 정해지면 프론트엔드 빌드 환경 변수 `VITE_PUBLIC_SITE_URL`에 앱의 공개 주소(예: `https://example.com`)를 설정한다. 빌드 시 HTML에 공개 주소와 로고 이미지의 절대 주소가 기록된다. 공개 주소가 없으면 로컬 확인용 상대 이미지 경로만 사용한다. 카카오톡이나 문자 미리보기는 외부에서 접속할 수 있는 배포 주소가 있어야 한다.
